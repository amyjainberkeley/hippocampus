# Code of conduct

Be direct and be kind. Critique the code, not the person. Assume the other person is busy and acting in good faith.

Not welcome here: harassment, personal attacks, discriminatory remarks, or publishing someone's private information. This applies in issues, pull requests, discussions and anywhere else this project is represented.

If something crosses that line, tell the maintainer privately. The one private channel on this repository is a [security advisory](https://github.com/amyjainberkeley/hippocampus/security/advisories/new); use it for conduct reports too. You will get a reply within a few days.
