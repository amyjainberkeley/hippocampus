# Daily Review Delivery

The owner's latest request adds usable product and website work alongside the
open capture gates. A better test harness alone is not this delivery.

## Observable Outcomes

1. Opening the app presents a daily review. Search starts with a query; History
   is chronological; Sessions groups evidence. A legacy Brief link still opens
   an appropriate view without adding a redundant sidebar destination.
2. The review identifies the last saved context, an observed return to an app,
   and a gap between available capture samples when supported. Every observation
   opens its evidence. Imports cannot establish screen activity. Sample counts
   and gaps never become percentages of active work or task-completion claims.
3. One day-scoped handoff can be previewed, copied or saved. Evidence is read
   again before export; missing, replaced and changed records cannot silently
   reuse an old approval. No external client receives data automatically.
4. The website gives the product name, a literal purpose, real synthetic-data
   app images, and short setup/privacy/source links. No conceptual glass art,
   fictional UI, unsupported automation claims or unqualified public download.
5. Verify the native flows in an isolated synthetic store, website rendering
   and navigation, and source regressions. Build/sign/install the actual native
   update and privately deploy the site. Record their identities independently.

## Capture Qualification

Continue the [observable gates](../audits/2026-09-07-observable-gates.md).
The native screen-only fixture, encrypted linked image, restart readback and
approved-client citation must agree. Fixture exposure, process liveness,
increasing counters and synthetic database tests are insufficient substitutes.
No permission reset, capture-policy relaxation or private-memory publication.

## Publication

Preserve unrelated work and data. Publish verified source to the existing
`codex/hippocampus-v1` branch and draft PR25 in the canonical GitHub repository.
Preserve the current private Sites audience. Domain launch and public binary
release remain separate owner and qualification decisions.
