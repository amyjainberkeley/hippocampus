## Product Boundaries To Build Next

- Focused-window capture is the current privacy boundary. Broader co-visible
  capture must classify every admitted window, exclude private/ambiguous sources,
  survive overlap/focus races and have an explicit user control. Reading unopened
  tabs requires a separate source, not a screenshot claim.
- Useful work insights require persisted active/idle samples, explicit unknown
  gaps, sleep/lock/pause handling and retention/deletion. Sample timestamps do
  not establish time worked. Application names do not establish productivity.
- Planned-versus-completed tasks require reviewable task records, stable source
  citations, change history and user confirmation. A visible checkbox or chat
  promise alone cannot authorize an action or prove an accomplishment.
- Deeper understanding must measure held-out source attribution, contradiction,
  temporal changes and abstention, not just fluent summaries. No autonomous
  follow-through until separate action permissions and audit history exist.
